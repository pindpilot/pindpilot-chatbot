# PindPilot AI

A mobile-first chat PWA, hosted at https://pindpilot.github.io/pindpilot-chatbot/ . Local conversation history, new/delete, copy/share, dark/light theme, voice question transcription, listen-to-answer, photo questions, and web search.

The browser app only contains a public Cloudflare Worker endpoint, never the Gemini API key. The key is a Cloudflare secret. The Worker uses Gemini's free-tier model for chat and photo questions and Tavily's keyless, rate-limited search for web results. If the free search limit runs out, web mode fails with a clear error rather than guessing. Web results can be stale or unreliable; check linked sources for important claims. There is no paid billing attached to this prototype.

**Privacy and limits:** History and resized photo previews are in this device's browser storage and can be removed with Delete Chat or by clearing site data. Messages and attached photos go to Gemini; web queries and results go to Tavily, then the results are included in Gemini's prompt. Avoid sensitive information. This is a small public pilot with a Cloudflare regional rate limit, not an authenticated or abuse-proof service. There is no cross-device history sync or login. Speech recognition may depend on Safari/device support and may process audio through the browser's service. Spoken answers use the device's speech engine. Free service quotas and provider availability may interrupt requests.
